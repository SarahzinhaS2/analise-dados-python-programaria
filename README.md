# Análise de Dados em Python | PrograMaria

Este repositório reúne o notebook e as atividades que fiz durante o curso de Análise de Dados em Python da PrograMaria, realizado entre 28/03/2025 e 23/05/2025.

Foi um dos meus primeiros contatos com Python e análise de dados. Durante o curso, aprendi a trabalhar com tabelas, DataFrames, gráficos e algumas formas de analisar e interpretar dados.

- Python para análise de dados
- Pandas

- Matplotlib
- Seaborn
- Plotly
- SciPy
- DataFrames
- Tabelas cruzadas
- Tabelas dinâmicas
- Estatística básica
- Valores faltantes

Também tive contato com a leitura de dados a partir de arquivos Excel e com o uso do Google Colab.

## Análises realizadas

Durante as atividades, trabalhei principalmente com dados relacionados ao mercado de trabalho, analisando informações como:

- idade
- gênero
- raça/etnia
- nível profissional
- cargo
- experiência na área de dados
- formação
- setor
- salário

As análises permitiram observar diferentes padrões nos dados e discutir questões relacionadas ao mercado de trabalho e às diferenças entre grupos.

## Sobre o notebook
